《我的丧尸世界》隐私政策

本政策适用于移动游戏《我的丧尸世界》（App Store 名称：Pixels Horror Zombie World，以下称“本游戏”）。 本游戏为单机游戏，游戏进度默认保存在您的设备本地。本游戏通过 Google AdMob 展示广告，广告 SDK 可能按本政策所述收集和使用有限的数据。

生效日期：2026 年 11 月 11 日

一、我们收集哪些信息

本游戏本身不要求您注册账号，也不会上传您的游戏存档。与广告相关的数据由广告 SDK 收集：

  • 设备标识符：广告标识符（IDFA，仅在您授权“跟踪”后可用）、应用开发商标识符（IDFV）、IP 地址；
  • 广告数据：广告展示、点击等互动记录，以及广告投放所需的粗略位置（由 IP 推断）；
  • 诊断数据：崩溃日志、性能与 SDK 运行状态，用于排查故障和防止欺诈。

若您拒绝“跟踪”授权，广告 SDK 不会获取 IDFA，本游戏仍可正常游玩，广告将按非个性化方式展示。

二、信息用于什么目的

  • 展示广告（在您授权时为个性化广告，否则为非个性化广告）；
  • 衡量广告效果、防止广告欺诈；
  • 诊断崩溃与性能问题，保障游戏稳定运行。

三、第三方服务

本游戏使用以下第三方服务，其数据处理受各自隐私政策约束：

  • Google AdMob（广告投放）：Google 隐私政策、AdMob 数据说明；
  • Google User Messaging Platform（同意管理，用于法律要求同意的地区）；
  • Apple App Tracking Transparency（系统级跟踪授权，仅 iOS）。

四、您的选择

  • iOS：设置 → 隐私与安全性 → 跟踪，可随时关闭本游戏的跟踪授权；
  • iOS：设置 → 隐私与安全性 → Apple 广告，可关闭个性化广告并重置广告标识符；
  • 卸载本游戏将停止本游戏相关的数据收集（已由第三方收集的数据按其政策处理）。

五、数据保留

本游戏不自行存储上述广告数据；第三方 SDK 的保留期限以其隐私政策为准。游戏存档仅保存在您的设备上，卸载即删除。

六、儿童

本游戏不面向 13 岁以下儿童，也不会主动收集儿童的个人信息。若您认为我们意外收集了儿童信息，请通过下方邮箱联系我们，我们会尽快处理。

七、政策更新

我们可能随 SDK 或法规变化更新本政策，更新后的版本将发布在本页面并更新生效日期。
